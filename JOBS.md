基于本项目的技术栈和代码特点，以下是相关的岗位信息和技能要求：

### 1. 算法工程师（图论方向）

**岗位职责：**
- 研究和实现图论相关算法，包括环基提取、最短路径、拓扑分析等
- 优化大规模图数据处理的性能，提升算法效率
- 设计和实现新的图结构识别算法（如特定长度的环检测）
- 与数据科学团队合作，将图论算法应用于实际业务场景
- 编写技术文档，维护算法库

**技能要求：**
- 扎实的数学基础，精通图论、线性代数、离散数学
- 熟练掌握 Python 编程，了解算法复杂度分析
- 熟悉常见图算法：BFS/DFS、最小生成树、最短路径、环检测
- 了解线性基（Linear Basis）、高斯消元等数学概念
- 具备代码优化能力，能够处理性能瓶颈
- 良好的算法设计和实现能力

**加分项：**
- 有 NetworkX、igraph 等图计算库使用经验
- 熟悉 C++/Java 等高性能语言
- 了解分布式图计算框架（如 GraphX、Giraph）
- 有 ACM/ICPC 或类似算法竞赛经验
- 发表过图论相关论文或专利

**工作年限：** 2-5年

**薪资范围：** 20K-40K/月（根据经验和能力）

### 1. Algorithm Engineer (Graph Theory)

**Responsibilities:**
- Research and implement graph theory algorithms including cycle basis extraction, shortest paths, topological analysis
- Optimize performance for large-scale graph data processing
- Design and implement new graph structure identification algorithms (e.g., cycle detection of specific lengths)
- Collaborate with data science teams to apply graph algorithms to real business scenarios
- Write technical documentation and maintain algorithm libraries

**Required Skills:**
- Strong mathematical foundation with expertise in graph theory, linear algebra, and discrete mathematics
- Proficient in Python programming with understanding of algorithm complexity analysis
- Familiar with common graph algorithms: BFS/DFS, minimum spanning tree, shortest path, cycle detection
- Understanding of linear basis, Gaussian elimination, and related mathematical concepts
- Code optimization capabilities to handle performance bottlenecks
- Strong algorithm design and implementation skills

**Nice to Have:**
- Experience with graph computing libraries like NetworkX, igraph
- Proficiency in high-performance languages like C++/Java
- Knowledge of distributed graph computing frameworks (GraphX, Giraph)
- ACM/ICPC or similar algorithm competition experience
- Published papers or patents in graph theory

**Experience:** 2-5 years

**Salary Range:** $30K-60K/year (USD equivalent, varies by location and experience)
