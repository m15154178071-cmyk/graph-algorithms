# 最小环基 (MCB) 求解算法套件

这是一个 Python **最小环基 (Minimum Cycle Basis)** 算法实现库。本套件提供了两种不同复杂度的求解器，覆盖了从简单的教学演示到针对一般图结构的优化求解。

---

## 🏗️ 求解器概览

| 版本 | 文件名 | 类型 | 适用场景 | 描述 |
|:---|:---|:---|:---|:---|
| **基础版** | `mcb_cycle_basis_simple.py` | 基础 | 教学、小规模图 | 纯 Python 实现。代码简单易读，无依赖，暴力求解。 |
| **优化版** | `mcb_cycle_basis_optimized.py` | 平衡 | 通用场景 | 引入启发式搜索和位运算。在复杂网络中速度显著优于基础版。 |

---

## ⚡ 性能基准测试

测试环境: Intel i7 / Windows 11.

**1. 结构化图 (Grid / Mesh)**

| 数据集 | 边数 | 基础版耗时 | 优化版耗时 |
|:---|:---|:---|:---|
| Grid 15x15 | ~420 | 0.07s | 0.09s |
| Grid 30x30 | ~1740 | 0.12s | 0.13s |

**2. 复杂网络 (Random / Scale-Free)**
*压力测试：无规律连接结构*

| 数据集 | 边数 | 基础版耗时 | 优化版耗时 | 提升 |
|:---|:---|:---|:---|:---|
| Erdos-Renyi (N=300) | ~900 | 0.68s | **0.32s** | **2.1x** |
| Barabasi-Albert (N=300) | ~900 | 0.72s | **0.22s** | **3.3x** |
| Watts-Strogatz (N=300) | ~1800 | 0.14s | 0.36s | - |

> **结论**: **优化版** 在处理随机图和无标度网络（如社交网络模型）时具有显著的性能优势。对于规则网格结构，两者性能相当。

## �🛠️ 使用说明

### 前置要求
- Python 3.8+
- `networkx` (仅用于运行 `benchmark.py` 生成测试数据，求解器脚本本身无此依赖)

### 1. 运行基准测试
运行完整的测试套件：

**Windows**:
```powershell
./run_bench.bat
```

**Linux / Mac**:
```bash
pip install -r requirements.txt
python benchmark.py
```

### 2. 单独运行求解器
直接调用脚本处理边列表文件：

```bash
python mcb_cycle_basis_optimized.py <输入文件> <输出文件>
```

**输入格式**:
文本文件，每行表示一条边（两个节点ID）：
```text
1 2
2 3
3 1
...
```

**输出格式**:
第一行：环的数量。
后续行：每个环包含的节点列表。
